# kairo.

Official Android downloads for **[Kairo](https://kairo.rishishah.in)**, the local-first focus timer, planner and insights app.

## Download

**[⬇ Download the latest APK](https://github.com/byrishi/kairo-releases/releases/latest/download/kairo.apk)**

Android 7.0 and newer · free · your data stays on your phone.

1. Download `kairo.apk` on your phone.
2. Open it. If asked, allow your browser to install unknown apps.
3. Install and open Kairo.

Every release lists the APK's SHA-256 checksum so you can verify the file.

Coming soon: Indus Appstore, Google Play, App Store.
